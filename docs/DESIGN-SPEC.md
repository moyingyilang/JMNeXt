# JMNeXt 界面设计规范（按风格分治）

> 目的：五套风格不是“换配色”，而是五种**材质语言**。每种材质有自己的一套规则，
> 混用就会变味（例：Miuix 本该是不透明卡片，却给它加玻璃，层次立刻糊掉）。

## 一、五种材质的分工

| 风格 | 材质语言 | 表面 | 模糊 | 阴影 | 圆角尺度 |
| --- | --- | --- | --- | --- | --- |
| WindowGlass | Windows 11 Acrylic | 半透明 + 发丝描边 + 上缘高光 | 有（backdrop blur） | 无（玻璃不投影） | 8/12/16 |
| FlatBlur | 扁平模糊 | 半透明 + 发丝边 | 有 | 无 | 8/12/16 |
| **Miuix** | HyperOS 实心卡片 | **完全不透明** | **无** | **无**（靠描边与底色分层） | 4/8/12/16/24 |
| **Material** | M3 Tonal | **完全不透明**（tonal surface） | **无** | **有**（level1/level3） | 4/8/12/28 |
| Plasma（动效性格，不是材质） | —— | —— | —— | —— | —— |

代码里由 `SurfaceCraft` 决定：`Acrylic` / `Glass` / `Blur` 才允许玻璃；
`Card`（Miuix）/ `Tonal`（Material）**强制不透明、禁用 backdrop 采样**。

## 二、通用规则（所有风格都适用）

### 间距
以 4dp 为步长：`2 / 4 / 8 / 12 / 16 / 24 / 32`。
- 页面左右内边距：16dp（列表页）或 12dp（密集页）；
- 卡片之间：12dp；卡片内元素之间：8dp 或 12dp；
- 区块标题与内容之间：8dp。

### 触控
- 可点区域**不小于 48dp**；
- 图标与文字之间至少 8dp；
- 列表行最小高度 56dp（单行）/ 72dp（双行）。

### 文字层级
只允许四种角色，不要临时造字号：
- 区块标题：`titleMedium`，权重 600；
- 列表主文案：`bodyLarge`；
- 说明/副文案：`labelSmall`，颜色 `textTertiary`；
- 数字/版本号等：`bodyMedium`，等宽数字可选。

### 状态
每个可点元素必须能看出四种状态：默认 / 按下 / 选中 / 禁用。
- 按下：透明度或缩放反馈（Miuix 用 0.97 缩放，Material 用水波纹）；
- 选中：用强调色（`accent`）或底色块，**不只靠加粗**；
- 禁用：`textTertiary` + 不可点。

### 分隔与描边
- 实心材质靠**描边或色阶**分层，不靠阴影（Miuix）；
- Material 靠**tonal 色阶 + elevation 阴影**分层；
- 玻璃材质靠**发丝描边 + 上缘高光**。

## 三、Miuix 专项（HyperOS 语言）

| 项 | 规则 |
| --- | --- |
| 表面 | 不透明；`surface1` 作底、`surface2` 作浮层、`surface3` 作弹层 |
| 圆角 | 卡片 16dp、列表组 12dp、按钮 24dp（胶囊） |
| 分层 | 描边 1px（`stroke`），**不用阴影** |
| 列表 | 分组展示：一组内行与行之间用 1px 分隔线，组与组之间留 12dp |
| 按压 | 0.97 缩放 + 轻微底色加深 |
| 强调 | 只在关键操作上用强调色，正文保持中性 |

## 四、Material 专项（M3）

| 项 | 规则 |
| --- | --- |
| 表面 | 不透明 tonal：卡片 `surfaceContainerLow`、浮层 `surfaceContainerHigh` |
| 圆角 | 卡片 12dp、大卡片 28dp、按钮 20dp（全圆角） |
| 分层 | elevation：卡片 level1(1dp)、浮层 level3(6dp) |
| 列表 | 行内不用分隔线，靠间距（16dp）与 tonal 色阶分区 |
| 按压 | 水波纹（`ripple`） |
| 强调 | 主操作填充 `primary`，次操作描边 `outline` |

## 五、玻璃专项（WindowGlass / FlatBlur）

| 项 | 规则 |
| --- | --- |
| 采样 | 表面实时采样背后内容（backdrop blur） |
| 表面色 | 0.40 不透明度（通透模式 0.22） |
| 模糊 | 中 8dp / 高 12dp（越糊越不像玻璃） |
| 饱和 | 模糊后用 `setToSaturation(1.5f)` 补偿发灰 |
| 描边 | 1px 发丝线 + 上缘 3dp 高光 |
| 禁用场景 | 阅读器正文、长列表行（性能与可读性都不划算） |

## 六、落地顺序

1. **令牌层**：`Tokens.kt`（间距/圆角/高度）—— 已具备，补齐每风格差异；
2. **组件层**：`GlassSurface`（已按 craft 分治）、`SettingCard`、`OptionSwitch`、
   `InfoRow`、`GlassTopBar`、`FloatingBottomBar`；
3. **页面层**：首页 / 详情 / 阅读器 / 搜索 / 收藏 / 历史 / 设置 / 关于 ——
   逐页按上面规则检查：间距是否 4 的倍数、行高是否达标、层级是否只有四种角色。

## 七、验收方式

每改完一层就编译 + 装机，用一件事判断有没有变味：
**同一页面在 Miuix 与 Material 下，分层手段是否各自成立**（Miuix 靠描边、Material 靠阴影），
而不是两套看起来一样。
